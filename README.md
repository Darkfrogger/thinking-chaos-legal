# thinking-chaos-legal
Legal information and privacy policies for Thinking Chaos applications.

## StoneKiller

- Page: [StoneKiller Privacy Policy](https://darkfrogger.github.io/thinking-chaos-legal/stonekiller/privacy.html)
- Source: [stonekiller/privacy.html](stonekiller/privacy.html)
- Status: **Draft for release review; not yet the final Play Store policy.**

Publisher: Patrick Reeb, an individual developer. Public privacy contact: business@reebs.org. Both were confirmed by the developer for this page.

Before the draft becomes final, confirm the exact distributed release and its dependencies and permissions, the target age groups, and the privacy, consent, security and retention arrangements for classes and any school relay. Check the policy against the Play Console Data safety answers and add an accessible policy link in the released app. Future app editions or in-app purchases are not asserted by this draft.

The text distinguishes local practice storage from optional transfers for classes, online media, exports and sharing. It makes no blanket promise about absent SDKs, tracking, data transfers or encryption.

## Hosting

GitHub Pages serves the root of the `main` branch. `.nojekyll` keeps this a plain static HTML site. The policy uses no client-side scripts or remote assets.

This repository is public. Commit only reviewed legal-page files. Never add application source, private documentation, student data, real recordings, secrets, credentials, environment files, signing keys or backups. Ignore rules are a precaution, not a secret scanner.
